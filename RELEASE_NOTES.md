# Thermal Valve Passport v0.3.0

Nonuniform-mesh completeness, explicit scale-law guardrails, and
reciprocal-root reflected kernels for the independent Lean 4 formalization of
the Thermal Valve Passport.

## Nonuniform-mesh passport

For an arbitrary mesh \(m_k\), define

```math
s_k
=
\frac{x_{k+1}-x_k}{m_{k+1}-m_k}
```

and

```math
\kappa_k
=
\frac{2}{m_{k+2}-m_k}
\left(s_{k+1}-s_k\right).
```

Lean proves that:

- every affine function of the mesh has zero divided curvature;
- adding an affine gauge leaves divided curvature unchanged;
- subtracting two observations with the same structural channel leaves an
  affine cross-gauge profile;
- the initial value, initial divided slope, and curvature sequence reconstruct
  every sample exactly;
- equality of nonuniform passports forces equality of observations;
- zero divided curvature forces the unique affine return fixed by the first
  value and first divided slope.

The reconstruction assumes only nonzero consecutive mesh gaps, nonzero
two-step spans, and invertibility of \(2\). It does not assume equal spacing or
an ordered field.

## Scale-law guardrails

For normalized prefixes \(C_M=1-T_M\), Lean proves

```math
2C_{2M}-C_M
=
1+T_M-2T_{2M}
```

and therefore

```math
2C_{2M}-C_M=1
\quad\Longleftrightarrow\quad
2T_{2M}=T_M.
```

The release also records exact if-and-only-if admissibility conditions for
first- and second-order Richardson extrapolation. The familiar cancellations
are then derived from explicit affine and quadratic scale laws instead of
being treated as automatic properties of the filter.

## Reflected reciprocal-root kernel

The reciprocal-root bracket

```math
R_\lambda x(n)
=
x_{n+2}-\lambda x_{n+1}+x_n,
\qquad
\lambda=q+q^{-1},
```

annihilates both \(q^n\) and \(q^{-n}\), their arbitrary linear combination,
and the finite reflected kernel

```math
\frac{q^n+q^Nq^{-n}}{1-q^N}.
```

Lean also proves the exact mismatch term produced when a kernel generated by
one reciprocal-root coefficient is read through another.

## Validation

The release remains gated by:

```bash
lake build --wfail
lake env lean ThermalValvePassport.lean
```

The CI also rejects proof placeholders and user axioms. No empirical
threshold, physical transition claim, special function, prime base, or
privileged complex-plane representation is introduced into the theorem
statements.
